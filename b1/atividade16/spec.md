# Atividade 16 -Streamlit / api

A atividade consiste em desenvolver uma aplicação simples utilizando Streamlit e uma API online de cartas.

https://deckofcardsapi.com/

O sistema deverá acessar a API, receber os dados no formato JSON e apresentar na tela as informações e a imagem de uma carta escolhida ou sorteada.

O objetivo é praticar o consumo de APIs, leitura de dados JSON e criação de uma interface simples com Python e Streamlit.

O sistema deverá simular o jogo entre dois jogadores, onde cada jogador recebe uma carta e o jogador com a carta de maior valor vence.
