Atividade 21- Form
Questão: Sistema de Cadastro de Produtos

Desenvolva um formulário utilizando Django para cadastrar produtos de uma loja.

O formulário deverá possuir os seguintes campos:

Nome do produto;

Marca;

Preço;

Quantidade em estoque;

Categoria (Informática, Eletrônicos ou Vestuário).

Requisitos:

Criar o formulário no HTML;

Utilizar o método POST;

Receber os dados na função views.py;

Utilizar request.POST.get() para recuperar os valores;

Exibir os dados cadastrados na própria página HTML.

Desafio extra: apresentar o valor total do estoque, multiplicando o preço pela quantidade.
